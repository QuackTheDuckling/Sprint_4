# Sprint\_4



Реализованы следующие тесты:



test\_add\_new\_book\_add\_two\_books — проверяет добавление нескольких книг и корректное увеличение словаря books\_genre.

test\_set\_book\_genre\_from\_list — проверяет установку жанра книге из списка допустимых жанров.

test\_get\_book\_genre\_existing\_name — проверяет получение жанра существующей книги.

test\_get\_books\_with\_specific\_genre\_existing\_books — проверяет получение списка книг с заданным жанром.

test\_get\_books\_genre\_two\_books\_different\_genre — проверяет корректность словаря books\_genre при добавлении нескольких книг с разными жанрами.

test\_get\_books\_for\_children — проверяет фильтрацию книг, подходящих для детей (без возрастного рейтинга).

test\_add\_book\_in\_favorites\_new\_book\_existing\_genre — проверяет добавление книги в список избранного.

test\_delete\_book\_from\_favorites\_added\_book — проверяет удаление книги из списка избранного.

test\_get\_list\_of\_favorites\_books\_two\_books — проверяет получение списка избранных книг.

test\_get\_book\_genre\_not\_set\_genre — проверяет поведение метода при отсутствии установленного жанра у книги (возвращается None).
